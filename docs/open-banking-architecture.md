TrueLayer Data V3 is selected for the real UK sandbox integration. See [the provider comparison and exact access boundary](open-banking-provider-selection.md).

The owner must establish the Console account and accept provider terms personally before free sandbox configuration can continue. The current decision document records all remaining connection, consent, sync, reconciliation, revocation and deletion acceptance work.
