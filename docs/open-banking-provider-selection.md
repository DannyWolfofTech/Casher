# UK Open Banking decision — 7 September 2026

**Selected provider: TrueLayer Data V3, using its hosted recurring-consent flow. Status: NOT PRODUCTION READY. No provider sandbox connection has been executed and no production agreement or credentials have been obtained.**

TrueLayer's current Data V3 documentation targets the UK and exposes a connection resource with a lifecycle, hosted authorisation and account/transaction scopes. This is a better fit for Casher's UK-only, read-only budgeting scope than extending the existing V1 experiment. Selection is conditional on TrueLayer accepting the consumer budgeting use case and confirming a viable regulatory and commercial arrangement. It does not mean production access has been approved.
